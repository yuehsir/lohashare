# 05_Developer_Prompts Reorganization Tool v0.1

## Purpose

This package reorganizes `05_Developer_Prompts/` into Current / 99_Archive structure.

## Use

1. Copy `docs/LOHAShare_AI_Platform/05_Developer_Prompts/` into your local repo and merge folders.
2. Run `RUN_MOVE_05_Developer_Prompts_Files_v0.1_20260601.bat` inside `05_Developer_Prompts/`.
3. Review files.
4. Move helper files and scripts to `07_Archive/Package_Export/05_Developer_Prompts_Reorg_20260601/` before final commit, or leave only README.md in the root.
5. Commit / Push.
6. Run Docs Governance Check and Docs Package.

## Important

Do not leave `.bat`, `.ps1`, `.csv`, or move-map `.md` files in `05_Developer_Prompts/` root after the reorganization is complete.
