# 05_Developer_Prompts

本資料夾集中管理 LOHAShare AI Platform 相關 Developer Prompts 正本。

## 管理原則

- Prompt 正本集中放在 `05_Developer_Prompts/`，不得放入 `02_Modules/`。
- 每個工具或模組 Prompt 類別底下採 `Current/` 與 `99_Archive/`。
- `Current/`：只放目前正式可使用的最新版 Prompt。
- `99_Archive/`：放同一類 Prompt 的舊版或已被取代版本。
- Prompt 若有 Markdown 版本，優先作為 AI / GitHub / Actions 可讀的工作版。
- DOCX Prompt 可作為閱讀版或交付版，但不應取代 Markdown 工作版。
