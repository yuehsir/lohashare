# Fallback_POC

路徑：`LOHAShare_AI_Platform/05_Developer_Prompts/Email_Notification/Fallback_POC`

## 用途

此資料夾屬於 `05_Developer_Prompts/`，用於保存開發工具 Prompt 正本。

## 可放置內容

- Replit Prompt
- Lovable Prompt
- Claude Code / Codex / Gemini Prompt
- n8n DocOps Prompt
- 與工具執行直接相關的提示詞正本

## 不應放置內容

- 模組規格正本，應放 `02_Modules/`
- Support / Incident 紀錄，應放 `04_Support_Knowledge_Base/`
- 搬移工具、一次性腳本與 ZIP，應封存至 `07_Archive/Package_Export/`

## 治理模型

每個 Prompt 類別底下應採：

- `Current/`：目前正式可使用版本
- `99_Archive/`：舊版或已被取代版本
