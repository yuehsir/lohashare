# 01_POC_Test_Logs

路徑：`LOHAShare_AI_Platform/02_Modules/Email_Notification/Fallback_POC/01_POC_Test_Logs`

## 用途

此資料夾屬於 `02_Modules/`，用於保存 LOHAShare AI Platform 的模組相關文件。

## 可放置內容

- 模組規格與 Module Specs
- 測試紀錄與 Test Logs
- 截圖與驗證畫面
- Decision Records
- Provider Notes
- 模組索引與模組說明文件

## 不應放置內容

- Developer Prompt 正本不得放在 `02_Modules/`，應放在 `05_Developer_Prompts/`。
- Support Ticket / Incident Log 不應放在模組資料夾主層，應放在 `04_Support_Knowledge_Base/`。
- 主 PRD 不應放在模組資料夾，應放在 `00_Main_PRD/`。

## 治理提醒

`02_Modules/` 不應整體硬套單一 `Current / 99_Archive` 模型；應依模組文件性質分別管理：規格可用 Current / Archive，測試與截圖應依日期或測試批次分類。
