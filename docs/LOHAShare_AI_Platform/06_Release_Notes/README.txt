06_Release_Notes

路徑：`LOHAShare_AI_Platform/06_Release_Notes`

#用途

此資料夾用於保存 LOHAShare AI Platform 的 Release Notes 與版本發布紀錄。

#可放置內容

- Release Note
- Phase Completion Note
- Workflow / Governance Check 升級紀錄
- 版本發布摘要

#不應放置內容

- 主 PRD 正文
- 模組規格正本
- Developer Prompt 正本
- 一次性工具包

#治理模型

Release Notes 本身為時間序列紀錄，暫不採 Current / 99_Archive。應以日期、版本號或階段名稱清楚命名。
