# LOHAShare_AI_Platform

本資料夾為 LOHAShare AI Platform 的文件治理與產品文件根目錄。

## 用途

- 保存 LOHAShare AI Platform 的主 PRD、架構治理、模組文件、SOP、Support KB、Developer Prompts、Release Notes 與 Archive。
- GitHub `docs/LOHAShare_AI_Platform/` 為 Working Source of Truth。
- Dropbox 僅作 Formal Archive / Distribution Copy，不作為工作中的唯一基準。

## 根目錄分類

- `00_Index/`：文件索引、最新資料夾基準、新對話交接文件。
- `00_Main_PRD/`：主 PRD 與主產品文件。
- `01_Architecture_Governance/`：架構治理、文件治理、格式策略、自動化策略。
- `02_Modules/`：模組規格、測試紀錄、截圖、決策紀錄、Provider Notes。
- `03_SOP_and_QA/`：SOP、QA 與緊急處理流程。
- `04_Support_Knowledge_Base/`：Support ticket、Incident log、Known Issues、Resolved Cases。
- `05_Developer_Prompts/`：所有開發工具 Prompt 正本。
- `06_Release_Notes/`：版本發布紀錄。
- `07_Archive/`：舊版、廢止、錯誤結構、輸出包與一次性工具封存。

## 管理原則

- 正式文件不得摘要化取代母本修訂。
- 新版文件應保留可追溯性，舊版依各資料夾規則放入 `99_Archive/` 或平台級 Archive。
- 若資料夾目前尚無文件，也應保留本 README 以說明用途。
