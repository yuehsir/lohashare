# 07_Archive

路徑：`LOHAShare_AI_Platform/07_Archive`

## 用途

此資料夾屬於 `07_Archive/`，用於封存不再作為 Current 使用的資料。

## 可放置內容

- 廢止資料夾結構
- 舊 ZIP 或輸出包
- 搬移工具
- 搬移對照表
- 一次性產出包
- Deprecated / Superseded 文件

## 不應放置內容

- 目前正式可引用版本
- 主 PRD Current
- 正在使用的 Developer Prompt
- 尚未歸類的工作中草稿

## 治理提醒

`07_Archive/` 是平台級封存區，不取代各主題資料夾中的 `99_Archive/`。同一主題文件舊版應優先放入該主題的 `99_Archive/`。
