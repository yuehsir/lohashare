# Known_Issues_FAQ

路徑：`LOHAShare_AI_Platform/04_Support_Knowledge_Base/Known_Issues_FAQ`

## 用途

此資料夾屬於 `04_Support_Knowledge_Base/`，用於保存支援、排錯、事件紀錄與已解決案例。

## 可放置內容

- Support Ticket
- Incident Log
- Known Issues FAQ
- Provider Debug History
- Resolved Cases
- 外部支援往來紀錄

## 不應放置內容

- 主 PRD 或產品規格
- Developer Prompt 正本
- 一次性 ZIP 輸出包
- 尚未分類的治理文件

## 治理模型

Support KB 不採單純 `Current / 99_Archive`，而採事件流程治理：

`Ticket / Incident → Debug History → Known Issue → Resolved Case`

若案例已解決，應移入或登錄至 `Resolved_Cases/`。
