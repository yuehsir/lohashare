# 01_Architecture_Governance

本資料夾已升級為二級分類架構，用於管理 LOHAShare AI Platform 的架構治理、文件治理、模組化治理、自動化策略、內容品質、Support KB 治理、工具升級判斷與視覺架構圖。

## 分類

- 00_Current_Index：目前治理文件索引與最新版本指引。
- 01_Document_Governance：文件治理、資料夾、檔名、版本、格式、同步規則。
- 02_Modular_Architecture：模組化架構、命名層級、主 PRD / MVP / Module / Derived Document 關係。
- 03_Automation_DocOps：GitHub Actions、n8n、Docs as Code、DocOps Roadmap。
- 04_Content_Quality_and_Consolidation：內容品質、整編、補正、稽核、v2.0 Clean Version 策略。
- 05_Support_KB_Governance：Support KB 管理規範。
- 06_Tooling_and_Escalation：工具分工、工程升級、Lovable / Replit / Claude / Codex 判斷規則。
- 07_Visuals：治理架構圖、命名層級圖、流程圖。

## 版本保存

每個主題資料夾採 Current / 99_Archive：

- Current/：只放目前正式可引用版本。
- 99_Archive/：放同一主題的舊版本。
